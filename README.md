# 🚀 Overview

**Camera Security** is a system for tracking your connected cameres. This application  was developed in **Python 3**.

The project combines multiple utilities into one modular tool, focusing on practical experience with:

- 🌐 Object tracking
- 🔌 Walking path tracking
- ⚡ Human id identification
- 🔐 Face / Emotion tracking
 
The goal of this project was to create a practical camera system that demonstrates real-world usage of Python for surveillance systems
